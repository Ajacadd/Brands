# مكتبة هوية الأجيال

مرجع فريق التصميم في أكاديمية هندسة الأجيال: الهوية الأم والبرامج والمشاريع والمنتجات، بشعاراتها وخطوطها وألوانها وتدرجاتها وضوابطها، وبرومبت لكل هوية.

افتح المكتبة من رابط GitHub Pages الخاص بهذا المستودع، ولا حاجة لتسجيل الدخول.

## المحتوى

- `index.html` — صفحة المكتبة، وفيها كل البيانات.
- `assets/` — الشعارات والخطوط والصور وأدلة الهوية (PDF).
- `source/` — الكود المصدري وسكربتات البيانات وأداة البناء (التفاصيل في `source/README.md`).

## التحديث

هذه نسخة ثابتة من المكتبة. النسخة الأصلية القابلة للتعديل على Claude. لتحديث هذه النسخة: صدّر البيانات، ثم شغّل `node offline/build.js --site` من مجلد المشروع، وارفع `index.html` ومجلد `assets` من جديد.
